# Module announce-subscribe

## Introduction

This module extends **plugin-announce** and **plugin-subscribe** to allow front-office users to subscribe to announcements. Users can subscribe to:

 
* A specific user (receive notifications when that user publishes an announce)
* A category (receive notifications for all announces in the category)
* A search filter (receive notifications for announces matching custom criteria)

A daemon periodically checks for new announcements and sends email notifications to subscribers whose subscriptions match the published content.

## Configuration

The module requires the following plugins to be installed and active:

 
*  **plugin-subscribe** (subscription management)
*  **plugin-announce** (announcement management)

Configure the following properties in `announce_subscribe.properties` :

 
*  `announce.subscription.notificationSubject` - Email subject for notifications
*  `announce.subscription.notification.maxAnnouncesPerEmail` - Maximum number of announces per notification email. Notifications are grouped by subscriber: each user receives a single emailcontaining all matching announces. When the number exceeds this limit, announces are split into multiple emails. Accepted values: **1 to 20** (default: **10** ).

 **Important:** The following Lutece core properties must be properly configured for email notifications to work:

 
*  `lutece.prod.url` - **Mandatory.** The production base URL of the portal (e.g. `https://myportal.example.com` ). If this property is not set, all links in notification emails will be broken.
*  `mail.server` - SMTP server address for sending emails
*  `mail.noreply.email` - No-reply sender email address used for notification emails

## Usage

The module provides an XPage application accessible at `?page=announce-subscribe` with the following actions:

 
*  `doCreateUserSubscription` - Subscribe to a user
*  `doCreateCategorySubscription` - Subscribe to a category
*  `doCreateSubscriptionFilter` - Subscribe to a search filter

Users can manage their subscriptions via the subscription management page provided by plugin-subscribe.
