# Module announce-subscribe

## Introduction

Ce module étend **plugin-announce** et **plugin-subscribe** pour permettre aux utilisateurs du front-office de s'abonner aux annonces. Les utilisateurs peuvent s'abonner à :

 
* Un utilisateur spécifique (notifications lorsque cet utilisateur publie une annonce)
* Une catégorie (notifications pour toutes les annonces de la catégorie)
* Un filtre de recherche (notifications pour les annonces correspondant à des critères personnalisés)

Un daemon vérifie périodiquement les nouvelles annonces et envoie des notifications par email aux abonnés dont les abonnements correspondent au contenu publié.

## Configuration

Le module nécessite l'installation et l'activation des plugins suivants :

 
*  **plugin-subscribe** (gestion des abonnements)
*  **plugin-announce** (gestion des annonces)

Configurez les propriétés suivantes dans `announce_subscribe.properties` :

 
*  `announce.subscription.notificationSubject` - Objet de l'email de notification
*  `announce.subscription.notification.maxAnnouncesPerEmail` - Nombre maximum d'annonces par email de notification. Les notifications sont regroupées par abonné : chaque utilisateur reçoitun seul email contenant toutes les annonces correspondant à ses abonnements. Lorsque le nombre dépasse cette limite, les annonces sont réparties dans plusieurs emails.Valeurs acceptées : **1 à 20** (défaut : **10** ).

 **Important :** Les propriétés suivantes du core Lutece doivent être correctement configurées pour que les notifications par email fonctionnent :

 
*  `lutece.prod.url` - **Obligatoire.** L'URL de base de production du portail (ex. `https://monportail.example.com` ). Si cette propriété n'est pas définie, tous les liens dans les emails de notification seront cassés.
*  `mail.server` - Adresse du serveur SMTP pour l'envoi des emails
*  `mail.noreply.email` - Adresse email d'expéditeur no-reply utilisée pour les notifications

## Usage

Le module fournit une application XPage accessible via `?page=announce-subscribe` avec les actions suivantes :

 
*  `doCreateUserSubscription` - S'abonner à un utilisateur
*  `doCreateCategorySubscription` - S'abonner à une catégorie
*  `doCreateSubscriptionFilter` - S'abonner à un filtre de recherche

Les utilisateurs peuvent gérer leurs abonnements via la page de gestion des abonnements fournie par plugin-subscribe.
